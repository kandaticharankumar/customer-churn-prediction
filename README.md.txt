# Predictive Machine Learning Customer Churn Pipeline

End-to-end classification pipeline to identify customer attrition indicators.

## Methodology
- **Preprocessing:** Feature scaling, categorical encoding, and SMOTE resampling for class imbalance.
- **Model Benchmarking:** Logistic Regression, Random Forest, and XGBoost.
- **Performance:** Achieved 85%+ ROC-AUC evaluated via Precision-Recall curves and confusion matrices.
